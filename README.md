### [Termin-API](https://github.com/roudihannanIT/termin-api) – Appointment Booking REST API
A backend for booking appointments in public services in Germany.

- **Stack:** Node.js, TypeScript, Express.js, PostgreSQL, Prisma ORM
- **Auth:** JWT authentication with role-based access control (RBAC)
- **Data consistency:** prevents double bookings under concurrent requests using database transactions, row-level locking and partial unique indexes
- **Testing:** integration tests with Vitest and Supertest, including a concurrency test with 50 simultaneous booking requests
- **DevOps:** Docker Compose for development and test environments, CI pipeline with GitHub Actions
